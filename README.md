# Research Data Management Tools Overview

A community-maintained comparison of tools for experimental
data and metadata management in research.

The repository contains structured information on research
data management platforms, including:

- primary purpose and use cases
- licensing
- deployment
- APIs and integrations
- supported data types
- parsable/importable file formats
- research areas
