# Contributing

Contributions are welcome.

## Updating an existing tool

1. Edit the appropriate file under `data/tools/`.
2. Provide a source supporting factual changes.
3. Use terms from `data/vocabulary.yaml`.
4. Open a pull request.

## Adding a new tool

Create:

data/tools/tool-name.yaml

Use an existing tool file as a template.

## Parsable / Imported File Formats

Only list file formats whose contents the software can
interpret, parse, or import as structured data or metadata.

Do not list formats that can merely be uploaded or stored.

## Sources

Where possible, use:

- official documentation
- official product documentation
- scientific publications
- institutional documentation
